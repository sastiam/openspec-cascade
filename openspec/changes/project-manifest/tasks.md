## Conventions

- Test first: write the tests of a task, see them fail, then implement. Scenarios marked as regression guards below only assert that something does not happen, so they may pass before the implementation; they are exempt from the failing-first rule.
- Every exported function has an explicit return type. Numbers other than -1, 0 and 1 come from named constants (`MANIFEST_CONSTANTS`, `EXIT_CODE_CONSTANTS`). Tests never read the real home folder or the real `XDG_CONFIG_HOME`.

# Tasks

All work is v1 only. v2 mode is being deprecated; do not change `src/facade/v2_pipeline.ts`.

## Dependencies

This change runs in a second unattended run, after `verify-contract`, `tasks-contract`, `project-manifest` and `cascade-explore` are implemented on the same branch. It relies on:
- `verify-contract`: the `alwaysVerify` config key and `taskChecks` in `src/facade/tasks.ts` (tasks 4.2 and 7.4).
- `tasks-contract`: `parseManualSteps` next to `lintManual`, and the tasks linter rules that `lintTasks` applies (tasks 4.3, 5.1 and 6.5).
- the docs-parity test `test/docs/cli_docs.test.ts`: every flag in the help text appears in `docs/cli.md`, and every subcommand appears as a backticked name in `docs/cli.md` and as `cascade.ts <name>` in `README.md` (tasks 2.1 and 6.5).
- `project-manifest` and `cascade-explore`: nothing at runtime; `status` names the `/cascade:explore` command that `cascade-explore` adds (task 6.4).

## Conventions

- Every task is test first: write the listed tests, see them fail, then implement. Tests marked "regression guard" protect behavior that already exists; they may pass before the change and are exempt from failing first.
- Code follows the repo's `eslint.config.js`: no magic numbers other than -1, 0 and 1 (use named constants in `src/config/constants.ts`), and explicit return types on every function.
- Facade tests in `test/facade/cascade_facade.test.ts` use the helpers already there: `WorkingEngine`, `completeTask`, `captureOutput`, `configFor`, `commitFixture` and `freshRepo`. Repo tests use `createTempGitRepo`, `addOpenSpecChange` and `runGitCommand` from `test/e2e/helpers/temp_repo.ts`. `createTempGitRepo` checks out `feat/e2e-test`.

## Conventions for every task

- Test first: run the new tests and see them fail before changing source. A test for a scenario that already passes before the change is a regression guard; each task names its guards, and they are exempt from the rule to rewrite a test until it fails.
- No comments inside function bodies. The `no-magic-numbers` rule ignores only -1, 0 and 1, so other numbers go into `TASKS_LINT_CONSTANTS`. Exported functions have explicit return types.

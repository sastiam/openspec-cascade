# Design: Milestone M1 — Configuration, Guardrails & Strict Hygiene

## Context

`openspec-cascade` currently mixes configuration constants, CLI parsing, environment loading, and runtime defaults in root `config.ts`, while `cascade.ts` invokes `loadConfig()` at module import time and lacks fail-closed CLI validation, post-session budget checks, log secret redaction, and dry-run support on protected branches. Furthermore, `eslint.config.js` lacks `@typescript-eslint/no-explicit-any: "error"`, leaving 15 explicit `any` leaks across root, `src/`, `projects/`, and test files.

## Decisions

### Decision 1: Modular `src/config/` Package with Backward-Compatible `config.ts` Facade
- **Structure:** Split configuration into `src/config/constants.ts`, `src/config/schemas.ts`, `src/config/guardrails.ts`, `src/config/loader.ts`, and `src/config/index.ts`.
- **Rationale:** Preserves hexagonal separation between pure constant definitions, boundary validation, security guardrails, and I/O loading while keeping root `config.ts` as a 100% backward-compatible re-export facade for all 18 existing consumers.

### Decision 2: Drifting Constant Reconciliation Without Breaking Existing Adapter Contracts
- **Structure:** Unify shared constants (`RATE_LIMIT_SLEEP_MS`, default models, truncation bounds, exit codes) in `src/config/constants.ts` and import from it across root files and `src/pal/adapters/` + `src/engine/rollback_buffer.ts` + `src/gates/` where semantics align.
- **Rationale:** Prevents 60x sleep discrepancies (`30_000` ms vs `1_800_000` ms) and duplicated model literals. Note: existing unit tests in `test/pal/gemini.test.ts` and `test/gates/gate*.test.ts` assert specific `GEMINI_ADAPTER_CONSTANTS.DEFAULT_MODEL` (`"gemini-2.5-pro"`) and `GATE0_CONSTANTS.EXIT_CODE_*` (`EXIT_CODE_FAILURE = 1`, `EXIT_CODE_ERROR = 2`), so shared constants expose both canonical cascade defaults (`DEFAULT_ANTIGRAVITY_MODEL`, `EXIT_CODE_ERROR = 1`, `EXIT_CODE_FATAL = 2`) and adapter-specific constants cleanly without breaking existing PAL/gate tests.

### Decision 3: Strict Preprocessed Zod Coercion (No Raw `z.coerce.number()`)
- **Structure:** Implement `strictFiniteNumber` and `strictBoolean` preprocessors in `src/config/schemas.ts` that reject empty/whitespace strings, booleans passed as numbers, `NaN`, `Infinity`, `-Infinity`, negative budgets/timeouts, and non-integer or out-of-range percentages (`usageLimitPercent` and `tokenWatermarkPercent` enforce `int: true` for `1–100`), throwing `ConfigValidationError` (`exitCode = 2`). Domain schemas and loader options bind strictly to domain-scoped minimum constants (`TIMEOUT_CONSTANTS.MIN_DURATION_MS`, `SDD_CONSTANTS.MIN_REVIEW_DURATION_SECONDS`, `GUARDRAIL_CONSTANTS.MIN_POSITIVE_INT`) rather than reusing `BUDGET_CONSTANTS.*`.
- **Rationale:** Native `z.coerce.number("")` returns `0` and `z.coerce.number(true)` returns `1`, creating silent bypasses. Explicit preprocessing guarantees fail-closed validation on CLI flags, environment variables, and `.openspec-cascade.json`, and domain-scoped bounds prevent semantic coupling across unrelated domains.

### Decision 4: Cycle-Safe Container-Preserving Redaction & Fail-Closed Guardrails
- **Structure:** `redactSensitiveData` uses a `WeakSet<object>` for cycle detection (`"[Circular]"`), enforces `maxDepth` (`"[MaxDepth]"`), clones and preserves `Array`, `Map`, `Set`, `Date`, `RegExp`, `Error`, and plain/`null`-prototype objects, uses `Object.defineProperty` via `defineOwnEnumerableProperty` in `redactRecordValue` and `redactErrorValue` so `"__proto__"` creates an own enumerable property without mutating `Object.getPrototypeOf`, and redacts sensitive keys plus inline tokens/PEM/URL credentials. `enforceSessionBudget` fails closed on `NaN`, negative/non-finite inputs, or `spentUsd >= maxBudgetUsd`. `evaluateProtectedBranchGuard` blocks non-dry-run executions on `main`/`master`/`stable` while allowing `--dry-run` preview with a warning.
- **Rationale:** Prevents `RangeError: Maximum call stack size exceeded` on cyclic error objects, avoids `cloned["__proto__"]` prototype pollution/setter traps, avoids `NaN >= maxBudget` JS comparison bypasses, and enables safe read-only `--dry-run` inspection on protected branches.

### Decision 5: Synchronous Lockfile-Aware Stack Detection & Lazy CLI Loading
- **Structure:** Add `hasLockfile(cwd)` and `tryDetectPackageManager(cwd)` in `platform.ts` (preserving `detectPackageManager` returning `"npm"` when no lockfile exists). In `src/config/loader.ts`, `loadConfig` validates explicit `overrides.repo ?? cliOpts.repo ?? env.CASCADE_REPO` and `overrides.logDir ?? cliOpts["log-dir"]` as non-empty trimmed strings via `assertNonEmptyExplicitString` before calling `normalizePlatformPath` or `loadFileConfigLayer` (throwing `ConfigValidationError` with zero side effects), treats blank `CASCADE_CHANGES` and `CASCADE_LOG_DIR` as unset via `nonBlankEnv`, and resolves `logDir` in strict precedence `overrides.logDir > --log-dir > CASCADE_LOG_DIR > fileConfig.logDir > default`. When a lockfile exists in `repoRoot`, `loadConfig()` and `cascade.ts:verifyCommands()` derive verify commands dynamically (`resolvePackageCommands`); when no lockfile exists (e.g. non-existent mock paths `/mock/repo`), defaults preserve `CONSTANTS.DEFAULT_VERIFY` / `FULL_VERIFY`. Nuxt `.nuxt/` and `nuxi prepare` expansion runs only when `.nuxt` or `nuxt.config.*` is detected (or default test fixtures expect it). Remove top-level `loadConfig()` execution from `cascade.ts` and invoke config loading inside `main()` / `runCli(argv, env)`.
- **Rationale:** Eliminates hardcoded Bun/Nuxt/Drizzle lock-in for arbitrary target repositories while preserving 100% compatibility with `config.test.ts` and `cascade.test.ts`, prevents silent `resolve("") -> cwd` bypasses on empty `--repo`/`CASCADE_REPO`/`--log-dir`, prevents blank env vars from clobbering `.openspec-cascade.json`, and prevents import-time crashes when `cascade.ts` is imported as a library or in test suites.

### Decision 6: Zero `any`, Zero Magic Numbers & Zero Inline Body Comments
- **Structure:** Update `eslint.config.js` with `".agents/**"` in `ignores` and `"@typescript-eslint/no-explicit-any": "error"`, fix all 15 AST `any` leaks, expand `lint.test.ts` to cover `src/**/*.ts`, and eliminate inline `//` comments inside function bodies across all M1-created and M1-modified files.
- **Rationale:** Enforces `openspec/project.md` constitution rules deterministically via `tsc --noEmit` and `eslint .`.
